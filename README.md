# API-Data-Mashup

1. Project Description: my project takes information potential applicants send and organizes them into a notion database

2. I used notion API accessed thru here --> www.notion.so/my-integrations.

3. Download the index.html and app.py files. Please place the index.html file into a sub-folder called templates. I've sent a .rar file of this on canvas as well

4. The workflow is very simple, users will enter the website and be prompted to fill in their name, email, and chosen track for a management trainee program

5. The platform is very barebones and doesn't have any other features besides the information input

6. I utilized AI to help me cleanup the integration of the Notion API into my python app and to make sure my app looked prettier in the index.html file
